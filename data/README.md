# Data (not in this repository)

The Jordà–Schularick–Taylor Macrohistory Database, Release 6, is third-party
data and is not redistributed here.

Download `JSTdatasetR6.dta` (or the Excel build) from:

https://www.macrohistory.net/database/

Place the file at:

    data/JSTdatasetR6.dta

The labeler and indicator constructor also accept `data/JSTdatasetR6.xlsx`.

Default and IMF-program overlays used by the labeler live in `overlays/`
and *are* in this repository.
